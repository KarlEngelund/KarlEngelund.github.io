# Minimal academic website

A dependency-free personal research site for GitHub Pages.

## Thesis and Google Scholar

The master’s thesis has a dedicated metadata-rich page at
`publications/bayesian-optimal-prediction.html` and is also listed on the static
`publications.html` browse page. This gives each work its own URL and keeps it reachable through
plain HTML links, as recommended by Google Scholar.

The searchable full text is stored at `publications/bayesian-optimal-prediction.pdf` and linked
from the thesis record using `citation_pdf_url`. If the GitHub username, Pages domain, or custom
domain changes, update that absolute URL in the thesis HTML page.
